# adapt2：恢复指定历史终端实现

来源：置顶“船”对话中“代码调整一下，选择自适应的时候，到达拐弯处，自动调回启发式的，出了拐弯处，变回去，根据曲率判断”之后的修改（2026-11-09）。本地历史包为 curvature_switch_2026-11-09/app。

SoftTerminalMPC.py 与该历史包逐字节一致，SHA256：045ae4f76f7ca7b1ea68ce78009a1d6f0e5f5a9cd064a88255d1616e44559d36。恢复该版阶段代价、终端自适应权重及软下降松弛计算，不保留 adapt1 的渐变和控制增量约束。

选择“自适应终端＋软下降（弯道自动切换）”。每船独立前看0.5秒，结合船位附近参考轨迹曲率；默认入弯门槛1.50 m⁻¹。两处曲率均降到入弯门槛的70%以下，连续3拍后恢复自适应。船还留在弯道时继续启发式。切换到启发式时使用原控制更新路径，切回后复用已编译的终端求解器。开始实验时清除上次弯道判定。

几何曲率、状态容器、参考预览及切换判定函数与历史包 AST 一致。只补充当前项目所需的界面配置保存/恢复及非NMPC禁用接口。入弯门槛保存为 NMPC_TERMINAL.turn_curvature，缺省使用1.50，不沿用adapt/adapt1的0.85门槛。其余保存的用户选择保持原值；若启动时是原启发式，请手动选择自适应选项。

修改范围为两个终端模块、控制器内的终端分支、实验开始时清理终端状态的一行代码、终端诊断导出及相关测试。未覆盖配置、日志或实验数据；其余控制算法的语法树和回归输出已核对。

15项当前适用测试通过，覆盖历史引擎哈希、半秒预判、三拍出弯、掉队船位保持、完整椭圆两次入弯/两次出弯、配置保存、其他控制算法及求解器缓存。两项旧adapt1专属测试和旧曲率接口测试标记为历史版本，不用于本次恢复验收。未操作实船。
