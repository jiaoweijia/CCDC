# adapt：NMPC 自适应终端与曲率切换

此版本恢复置顶“船”对话中的位置优先自适应终端、目标下降率和软下降机制，并增加按参考轨迹曲率自动切换。Qt 组件由 `SoftTerminalPanel.py` 动态加入轨迹绘图区下方。

## 使用

选择 NMPC，在绘图区下方选择“自适应终端＋软下降（位置优先）”。其他控制律下该面板置灰，终端优化器不参与控制。

默认参数：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| 未来 H 步下降目标 | 10% | H 步预测误差能量的目标下降比例 |
| H | N（10） | 0 显示为 N，使用完整预测时域 |
| 松弛惩罚 λ | 10 | 归一化目标中的松弛平方惩罚 |
| 按曲率切回原启发式 | 开启 | 仅自适应终端模式使用 |
| 入弯门槛 | 0.850 m⁻¹ | κ ≥ 此值时切换原启发式终端 |
| 出弯门槛 | 0.700 m⁻¹ | κ ≤ 此值时恢复自适应终端 |

两个曲率门槛之间保持当前模式。入弯期间完全使用原启发式 NMPC 更新路径，不加软下降约束；模式选择框仍保留自适应偏好。出弯后清除上一段自适应能量比较历史，保留实际 ARX 记忆和滚动控制初值。关闭曲率开关可全程使用自适应终端；也可选择固定终端权重或原启发式对照。

曲率使用相邻三个参考点的外接圆曲率，单位 m⁻¹，与采样速度无关。轨迹跟踪使用每艘船自身带编队偏置的几何参考预览；路径模式使用前一参考点、当前参考点和下一参考点估算。没有可用曲率时不保持旧的弯道锁存。曲率门槛需根据实际参考轨迹调整，持续大曲率的圆形轨迹可能全程处于启发式模式。

设置保存到原 `config.ini` 的 `[NMPC_TERMINAL]` 节，下次启动恢复。状态栏显示实际模式、曲率、预测能量、松弛量和自适应倍率。NMPC 的 Excel 数据增加相应终端诊断列，便于按实际生效模式分析实验。

## 计算机制

自适应终端矩阵为 `P_k = σ_k P_0`，倍率限制在 `[1, 20]`，根据位置误差相对目标下降进展更新；固定终端模式使用 `σ=1`。

软约束为 `V_H ≤ (1−ρ)V_0 + s`，其中 `s ≥ 0`；目标中加入 `λ(s/energy_scale)²`。下降率是整个 H 步时域的比例，不是每拍实测误差下降比例。先求位置优先的预测方案，再在最多增加 1 cm 的位置预算内协调原 NMPC 目标、终端代价和软下降。

通过 ARX 独立滚动验证优化结果的输入边界、速度边界、软下降和位置预算。求解异常时可使用经过检查的备用方案；没有经过检查的可行方案时停止本次运行并显示原因。

这是预测误差的软下降要求，实船效果仍需实验验证；不把有松弛的预测下降视为实际闭环稳定性证明。本次没有增加起步、推力或电池补偿。
